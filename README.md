# Passo Leve

Loja virtual demonstrativa de calçados infantis, criada para o portfólio de Sabrina Lima.

## Funcionalidades
- Catálogo com tênis, galocha, bota de neve e pantufa.
- Filtros por categoria, escolha de tamanho e sacola interativa.
- Layout responsivo e preços fictícios em euros.

## Executar
Abra `index.html` no navegador. O projeto usa HTML, CSS e JavaScript, sem instalação.

## Demonstração
https://passo-leve-sabrina.limaucello.chatgpt.site

O site está privado no momento. Produtos, valores e compras são fictícios. As fotos ilustrativas foram geradas para este projeto.
